### Featured Open-Source Projects (Production Starter Kits)

#### 1. AI & Hybrid Data Platform
* **[pg-civic-rag](https://github.com/Swatikantamishra8/pg-civic-rag)**: Production-grade hybrid semantic + SQL vector retrieval engine for public welfare schemes and institutional archives. Powered by FastAPI, PostgreSQL (pgvector HNSW indexing), Redis, Celery, and local Ollama models (BGE-M3 & Qwen 2.5). Engineered for on-premise, privacy-preserving deployments with zero external API egress.

#### 2. Legacy Modernization & AI4SE
* **[legacy-lens-ai](https://github.com/Swatikantamishra8/legacy-lens-ai)**: Static analysis and LLM-assisted reverse-engineering toolkit for legacy monolithic stacks. Uses Tree-sitter AST parsers to map cyclomatic complexity, construct schema dependency DAGs, and generate automated pytest/PHPUnit regression suites via local open-weights code models (Qwen2.5-Coder / DeepSeek-Coder).

#### 3. Database Reliability & Financial Systems
* **[pg-zero-downtime-kit](https://github.com/Swatikantamishra8/pg-zero-downtime-kit)**: Production reference kit for non-blocking PostgreSQL migrations, query-plan EXPLAIN audits, pgvector HNSW vs. IVFFlat benchmark harnesses, and an idempotent SHA-256 financial webhook engine designed to prevent double-charging during network drops.

#### 4. Computer Science Pedagogy & Systems
* **[daa-dbms-open-lab](https://github.com/Swatikantamishra8/daa-dbms-open-lab)**: University laboratory curricula for *Design and Analysis of Algorithms (DAA)* and *Relational Query Optimization*. Features automated test-driven grading harnesses (pytest & SQL assertion runners) for algorithm analysis and EXPLAIN ANALYZE execution plan verification.
* **[AuralisOS](https://github.com/Swatikantamishra8/AuralisOS)**: Research Linux distribution engineered for ultra-low-memory (<95MB Idle RAM) efficiency on low-cost hardware, featuring a modern Wayland compositor and modular container builder.
* **[MacSCP](https://github.com/Swatikantamishra8/MacSCP)**: Native dual-pane file management and SFTP/SCP client engineered with Tauri v2, Rust backend, and TypeScript.
